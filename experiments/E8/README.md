# E8. Идея I42, пункт (A): вклад нулей $g$

Запуск: `uv run experiments/E8/run.py` (проверки и основной расчёт; лог — `run.log`, данные пар — `data/pairs_*.json`).

## Вопрос и исход, опровергающий гипотезу (записано до расчёта)

Задача: $L_ay=-y''(x)-a(x)y''(-x)$ на $(-1,1)$, $y(\pm1)=0$,
$a=(x^2-\tfrac14)^2\exp\bigl(\varepsilon(x^3/3-x/4)\bigr)$, $\varepsilon=3$. Тогда $q=a/Ra=e^{2h}$,
$h=\varepsilon(x^3/3-x/4)$, $r=e^{h/2}$, $b=(x^2-\tfrac14)^2$ (нули порядка $m=2$ в $\pm\tfrac12$),
$g=r'/r=\tfrac\varepsilon2(x^2-\tfrac14)$, то есть $g(\pm\tfrac12)=0$ с простым нулем ($k=1$).
Модельные серии по I42/I41: $N_+=\lbrace\pi(n-\tfrac12)/\ell_+\rbrace$, $N_-=\lbrace\pi m/\ell_-\rbrace$,
$\ell_\pm=\int_0^1(1\pm b)^{-1/2}dx$.

Что измеряется. На резонансных парах $\nu\in N_+$, $\nu'\in N_-$ ($\lvert\nu^2-\nu'^2\rvert\le80$, $100\le\nu\le2000$)
берём два собственных значения $\lambda_1,\lambda_2$ около $\nu^2,\nu'^2$. В блоке $2\times2$
$\begin{pmatrix}\nu^2+d_1&X\\Y&\nu'^2+d_2\end{pmatrix}$ получаем
$$
(\lambda_1-\lambda_2)^2=(\nu^2-\nu'^2+d_1-d_2)^2+4XY,\qquad
\lvert X\rvert_{\mathrm{eff}}:=\sqrt{\lvert XY\rvert}.
$$
Диагональные сдвиги $d_{1,2}$ оцениваются по изолированным соседям той же серии
($\lambda_k-\nu_k^2$ для $k\pm1,k\pm2$, у которых ближайшая модельная точка другой серии дальше 400 по $\lambda$).
Значение «только модель» ($d_1=d_2=0$) тоже приводится, но смещено: смещение $2\Delta(d_1-d_2)$ сравнимо с $4XY$.

Гипотезы о показателе $\theta_{\mathrm{eff}}$ в $\lvert X\rvert\asymp\nu^{\theta_{\mathrm{eff}}}$:

- (A) в буквальной формулировке: нули $b$ с $g=0$ не учитываются, $m_\ast=0$, $\lvert X\rvert$ ограничен ($\theta_{\mathrm{eff}}=0$).
- Критик: вклад нуля $x_j$ равен $\nu^{(m_j-k_j)/(m_j+1)}$, здесь $\nu^{1/3}$.

Операционализация (до расчёта). Основная величина — наклон $p$ в $\log\lvert X\rvert_{\mathrm{eff}}\approx p\log\nu+\mathrm{const}$
по всем обработанным парам и по огибающей (максимум в окнах $[100,300),[300,800),[800,2000]$); доверительные
границы 5–95% — бутстреп по парам с зерном 20261025.

- Опровергает (A) в буквальной форме (нужно учитывать вклад нулей $g$): интервал для $p$ исключает $0$ и содержит $1/3$ (с $\lvert X\rvert/\nu^{1/3}$ без тенденции к нулю в трёх окнах).
- Согласуется с ограниченностью и опровергает формулу критика: интервал исключает $1/3$ и содержит $0$.
- Остальное: расчёт не различает; границы возможного вывода тогда называются в выводе.
- Граничный вклад в $x=0,1$ даёт $O(1)$ и занижает $p$ при малых $\nu$; поэтому подмножество $\nu\ge300$ приводится отдельно.

Ожидаемое значение $\lvert X\rvert$ для оценки масштаба (стационарная фаза, один нуль $x_0=\tfrac12$,
$g\approx g'(x_0)(x-x_0)$, $g'=\varepsilon x_0=1{,}5$, $\Phi'\approx-(x-x_0)^2$):
$\lvert X\rvert\sim\nu^{1/3}\cdot g'\cdot3^{2/3}\cdot2\int_0^\infty s\sin s^3ds$ с точностью до множителя в определении $X$, порядка $2\ldots3\,\nu^{1/3}$.
Это оценка масштаба, а не проверяемое утверждение: нормировка элемента $V_1$ не выписана.

## Контроли (ожидания записаны до расчёта)

| Контроль | $a$ | Ожидание |
| --- | --- | --- |
| EVEN | $(x^2-\tfrac14)^2$ (чётный, C5; $g\equiv0$) | спектр вещественен, $X=0$; $\lvert X\rvert_{\mathrm{eff}}$ на уровне погрешности оценки $d$ |
| M1 | $(x^2-\tfrac14)(1+x/4)$ ($m=1$, $g(\pm\tfrac12)\ne0$) | рост $\nu^{1/2}$, $\lvert X\rvert/\nu^{1/2}\approx0{,}5\ldots0{,}6$ (в I42: расщепление$/\nu^{1/2}\approx1$ у точных резонансов) |

метод считается непригодным для вывода по MAIN.

## Проверка метода (предусмотренные проверки)

1. $a=1/2$: точный спектр $\lambda=1{,}5\pi^2(k+\tfrac12)^2$, $0{,}5\pi^2(k+1)^2$; пары около $\nu\approx150,600,1500,1990$ при трёх разрешениях; допуск $10^{-5}$ по $\lambda$.
2. Интегратор против scipy DOP853 (rtol $10^{-12}$) на комплексных $\lambda$; допуск $10^{-8}$ отн.
3. $\ell_\pm$: quad против mpmath (30 знаков).
4. Строки таблицы I42 (расщепление для $a=1/2+x/4$ и $m=1$).
5. Плотная коллокация Чебышёва ($N=1000,1400$) для пар с $\nu\le150$.

## Отклонения от плана

- Порог изоляции соседей 400 по $\lambda$ при $\nu<290$ не выполняется ни для одного соседа (шаг серий в $\lambda$ около $2\pi\nu/\ell\approx650$ при $\nu=100$). Поправка $d$ там не определена, 10 пар из 28 отброшены. Эффективный диапазон поправленных значений основного прогона ($\lvert\Delta\rvert\le80$) — $\nu\ge290$.
- В основном прогоне 18 пар на случай. Добавлен расширенный прогон `E8_DMAX=200` (61 пара, обработано 44), параметры те же. В плане его не было.
- Фазовый анализ `fit.py` придуман после просмотра основного расчёта: он апостериорный и критерием плана не является.

## Вывод

По критерию плана (интервал для $p$ исключает 0 и содержит 1/3) MAIN выдерживает его только в расширенном прогоне; в основном интервал содержит и 0, и 1/3, и расчёт не различает. Контроли по сырым наклонам критерий не прошли надёжно: для M1 наклон $+0{,}76\ldots0{,}93$ при ожидаемых 0,5 (отклонение больше допустимых 0,15), потому что $\lvert X\rvert$ осциллирует по паре (минимумы 1–2 при максимумах 20–60). Поэтому сырые наклоны вывода не несут. Апостериорная подгонка с фазой на контролях даёт $p=0{,}55$ и $0{,}75$ (отклонения 0,05 и 0,08), для MAIN $p=0{,}30\ldots0{,}35$, невязка при $p=1/3$ вдвое меньше, чем при $p=0$.

Данные согласуются с рассуждением критика (вклад нулей $g$, $\lvert X\rvert\sim\nu^{1/3}$ при $m=2$, $k=1$) на $\nu\in[100,2000]$ и не согласуются с формулой $m_\ast$ без этого вклада ($\lvert X\rvert$ ограничен): $\lvert X\rvert$ доходит до 46–58 и растёт от окна к окну (медиана 23 → 43 в расширенном прогоне). Это вывод по апостериорной модели; показатель в $[0{,}25;0{,}4]$ данные не разделяют.

## Что не проверено

- Диапазон $\nu\le2000$; 44 пары; в основном прогоне $\nu<290$ без поправки $d$.
- Оценка $d_1-d_2$ по соседям — не независимый метод; для MAIN нет контроля с известным $X\ne0$.
- Фазовая модель без граничного члена $O(1)$ в $x=0,1$, форма $\lvert\cos\rvert$ не обоснована, подгонка сделана после просмотра данных; на M2 систематика $p$ около $0{,}08$.
- Только $\varepsilon=3$; $\varepsilon=1$ из критики не считался.
- Шаги 3–5 идеи (регулярность порядка $\theta$, теорема S20) опыт не затрагивает.
